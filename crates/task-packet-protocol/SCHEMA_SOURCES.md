# Vendored protocol schemas

These files are exact copies of Task Packet Protocol version 1 schemas from
the sibling `task-packet-system/schemas` repository as of 2026-08-01.

Run `scripts/sync-task-packet-schemas.sh` from the Vibe repository root to
refresh them from a local protocol checkout and update `schema-checksums.txt`.
CI verifies the checked-in checksums without requiring the sibling repository.
